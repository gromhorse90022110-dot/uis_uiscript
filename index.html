Таймер без тела просто обновляет реактивные надписи. Например, чтобы часы шли сами, достаточно:

            
заголовок "{сейчас()}"

Никакого пусть тик = 1 писать не нужно — таймер сам пересчитает {сейчас()} и обновит надпись.


            
Сеть и API

            
Действие запрос обращается к серверу и записывает ответ в переменную. Запрос асинхронный — интерфейс обновится сам, когда данные придут.

            
пусть погода = "…"

окно "Погода"
  заголовок "Сейчас: {погода}"
  кнопка "Обновить"
    нажми:
      запрос "https://api.example.com/current" в погода

            
    
              
  • Синтаксис: запрос "URL" в переменная
    • 
              
  • С методом и телом: запрос "URL" метод "POST" тело "{\"x\":1}" в ответ
    • 
              
  • JSON определяется автоматически; если сервер вернул текст — придёт строка.
    • 
              
  • Ошибка/таймаут (15 с) → переменная станет null, в консоли будет подробность.
    • 
              
  • Извлечь поле JSON: путь(ответ, "main.temp") — точка и [индекс] работают.
    • 
              
  • Только http(s). Сервер должен разрешать CORS, иначе браузер заблокирует ответ.
    • 
              
  • При перезапуске кода незавершённые запросы отменяются; лимит — 10 одновременных.
    • 
              
  • Английские алиасы: fetch, request, get, post, метод/method, тело/body.
    • 
            


            
Встроенные функции

            
    
              
  • число(x), округлить(x, 2), пол(x), потолок(x)
    • 
              
  • путь(obj, "a.b[0].c") — вложенное поле JSON
    • 
              
  • случайное(1, 10), абс(x), мин(a, b), макс(a, b)
    • 
              
  • длина(x), верхний(s), нижний(s)
    • 
              
  • число_ли(x) — можно ли прочитать значение как число ("12", "1,5" — да; "abc" и пустая строка — нет)
    • 
              
  • обрезать(s) — убрать пробелы по краям; пусто(x) — значение пустое ("", null, пустой список)
    • 
              
  • сейчас() — время, дата() — дата
    • 
              
  • секунд_до("2026-06-15 18:00") — сколько секунд осталось до даты. Для прошедших дат число отрицательное. Дата без времени («2026-06-15») считается с полуночи по местному времени.
    • 
            


            
Свои функции

            
функция привет(имя):
  сообщение "Привет, " + имя
  вернуть "готово"

вызвать привет("Мир")
пусть ответ = привет("Друг")

            
Параметры разделяются запятыми. вернуть возвращает значение из функции. Вызов — через вызвать или прямо в выражении.


            
Реактивность

            
Если в строке есть {переменная} — надпись обновляется сама при её изменении:

            
пусть счётчик = 0
текст "Счётчик: {счётчик}"
кнопка "+"
  нажми:
    счётчик = счётчик + 1

            
Не нужно писать установить — надпись обновится сама. Работает для заголовок, подзаголовок, текст, кнопка, ссылка, окно, карточка, галочка.

            
Важно: если вызвать установить имя "..." — реактивность у этого элемента отключается.


            
Условные свойства

            
Свойство с условием применяется, только если условие истинно:

            
кнопка "Плюс"
  выключен если счётчик >= 10
  невидимый если пусто(имя)

            
Работает для выключен, невидимый, жирный, курсив, центр. Обновляется автоматически при изменении переменных.

            
Важно: в условиях {…} не нужны — пишите выражение напрямую: выключен если счётчик >= 10, а не выключен если {счётчик >= 10}.


            
English syntax

            
Основной синтаксис — русский, но большинство ключевых слов можно писать и по-английски, в том числе вперемешку. Служебные слова внутри выражений (and, or, not) распознаются встроенно.

            
window "Demo"
  heading "Hello"
  field name
  button "Greet"
    click:
      if name == "" or name == "?"
        message "Enter a name"
      else
        message "Hello, {name}!"

            
    
              
  • если / иначе / иначе если = if / else / else if (или elif)
    • 
              
  • и / или / не = and / or / not
    • 
              
  • повторить 3 раза = repeat 3 times
    • 
              
  • пусть = let, функция / вызвать / вернуть = function / call / return
    • 
              
  • каждую секунду, через 2 сек = every second, after 2 sec
    • 
              
  • Элементы: window, heading, subheading, text, button, field, checkbox, slider, textarea, image, video, link, divider, row, column, card, list, select, option
    • 
              
  • Свойства: background, color, size, bold, italic, center, hint, width, height, padding, radius, border, shadow, opacity, hidden, min, max, value, url, disabled
    • 
              
  • События: click, change, hover, leave
    • 
              
  • Действия: show, message, set, add, remove, clear, hide, open, toggle, enable, disable, focus, fetch, request
    • 
              
  • Сеть: fetch "url" into result, method, body
    • 
              
  • Функции: number, round, floor, ceil, abs, min, max, random, length, upper, lower, now, date, path, seconds_until, is_number, trim, empty
